# @kazah_teams — Gradle Source Project

Собираемый проект Minecraft 1.21.11 / Fabric: **876 Java-файлов в `src/main`, 35 файлов сохранённой дополнительной логики в `src/recovery` и 195 ресурсов в `src/main/resources`**. Все 180 ресурсов пространства `assets/wexside` из бинарника учтены; девять отличающихся версий сохранены отдельно в `evidence/binary-resource-variants`.

**Точное восстановление исходного клиента остаётся частичным.** В предоставленных артефактах удалены тела отдельных классов действий, инициализация и часть метаданных настроек. Они описаны в `evidence/RECOVERY-REPORT.md`. Вымышленные реализации отсутствующих действий не добавлены. Исходный скомпилированный клиент не используется как скрытая зависимость.

## Сборка и запуск

Нужен JDK 21 или новее. Проверки выполнены на Windows с Oracle JDK 25.0.3, целевой формат классов — Java 21. Gradle 9.7.1 включён через wrapper. При первой сборке требуется доступ к репозиториям зависимостей и файлам Minecraft.

```powershell
Set-Location 'C:\Users\artem\Documents\Codex\2026-11-03\m\outputs\WexSideSRC'
.\gradlew.bat clean build
.\gradlew.bat runClient
```

После распаковки на другом компьютере измените только путь `Set-Location`. Если Java отсутствует в `PATH`, задайте `JAVA_HOME` на установленный JDK.

Устанавливаемый мод: `build\libs\wexside-client-1.0.0-recovered.jar`. Поместите его в `mods` экземпляра Minecraft **1.21.11 / Fabric Loader 0.19.3** вместе с **Fabric API 0.141.6+1.21.11**. Шесть библиотек TwelveMonkeys ImageIO уже вложены в мод. Для открытия панели войдите в мир и нажмите **Right Shift**.

## Без отдельного remap исходников

Java-файлы уже используют именованный namespace **Yarn 1.21.11+build.6**. Дополнительная утилита или команда remap исходников не нужна. Задача `remapSourcesJar` отключена; исходники и создаваемый `sources.jar` остаются именованными.

Fabric Loom 1.17.12 выполняет обычное сопоставление игровых зависимостей и `remapJar` при упаковке устанавливаемого Fabric-мода в intermediary namespace. Это не обещание сборки вообще без любых mapping-стадий.

## Состав

- `src/main/java/ru/wexside` — код запускаемого клиента; реестр содержит 122 записи: 103 обычных модуля и 19 ESP-функций.
- `src/main/resources` — метаданные Fabric, mixins, текстуры, шрифты, звуки и шейдеры.
- `src/recovery/java` — сохранённые части CrystalAura, AutoWarden, FireworkBoost/ElytraMotion и моста DonMarket. Они компилируются обычной сборкой и включены в исходный JAR, но не регистрируются автоматически в клиенте при неизвестных настройках или привязках событий.
- `src/test`, `src/recoveryTest` — исполняемые регрессионные проверки; `src/smoke` — отдельный тестовый мод, отсутствующий в release JAR.
- `tools/verify.ps1` — JVM/ASM и проверка ссылок на члены классов без запуска их статических инициализаторов.
- `evidence` — журнал проверок, происхождение, инвентари, границы восстановления и альтернативные ресурсы.

Профили разработки: `run/config/wexside/*.wex`; логи: `run/logs/latest.log`; миры: `run/saves`. В установленном клиенте эти пути отсчитываются от папки соответствующего экземпляра игры.

Заголовок окна, имя панели, отображаемое имя Fabric-мода и стандартный профиль — `@kazah_teams`. Внутренние пакеты и mod ID `wexside` сохранены для совместимости.

## Проверки

```powershell
.\gradlew.bat check
.\gradlew.bat runClient -Psmoke
powershell -ExecutionPolicy Bypass -File .\tools\verify.ps1
```

`check` запускает проверки событий, клавиш, конфигурации, цветовых значений, 261 проверку кинематики с независимым математическим эталоном, а также проверки сохранённых flight/warden/crystal/donmarket-компонентов. Преднамеренно выброшенное исключение тестового listener печатает ERROR; результат определяется строкой `RECOVERY CHECKS PASS` и кодом завершения.

`-Psmoke` проверяет реестр и конфигурацию, brightness, timer, альтернативную клавишу меню, владение дочерними элементами potion popup и 19 GPU-проверок mask/blur/четырёх material/трёх energy-режимов с чтением пикселей. Затем держит панель открытой 80 клиентских тиков, записывает `run/smoke-result.txt` и завершает клиент.

Финальные результаты приведены в `evidence/SOURCE-ACCEPTANCE.md`. Полная проверка игрового действия каждого модуля, переподключения, длительной стабильности и FPS не выполнена. Успешная сборка и короткий smoke не означают 100% восстановления всех исходных модулей.
